# 시험 기록

2026-09-16 기준 개발 환경에서 검증했습니다. 배포 완료 또는 모든 AI 앱에서의 호환성 보증은 아닙니다.

## 통과

- 원본 세 파일의 SHA-256 및 양식 선택 규칙.
- 사업계획·결과보고 HWPX 생성, 필수 ZIP/XML 구성·표 병합 구조 검사.
- HWPX 원본 header.xml 및 BinData 바이트 보존.
- 1PAGE HWP 생성, OLE 스트림 재구성, 레코드 재파싱, DocInfo·FileHeader 보존.
- 예산 합계 불일치, 결과보고의 추정 집행액, 미등록 출처 ID, 1PAGE 과다 분량 거절.
- OAuth 등록 → PKCE → 동의 → 토큰 발급 → MCP 초기화 → 세 양식 생성 → 서명 URL 다운로드 통합시험.
- 인증 없는 MCP 접근, 재사용한 인증 코드, 회전 전 갱신 토큰, 변조·만료 다운로드 링크, 다른 연결의 문서 조회 거절.
- 별도 문서 렌더러에서 예시 1PAGE를 1쪽으로 확인. 사업계획·결과보고 예시는 3쪽으로 렌더됨.

자동 시험: `pytest -q` — 8개 통과. 의존 도구의 deprecation warning 2건은 기능 실패가 아닙니다.

## 남은 검증

- Render 배포 및 외부 HTTPS 주소의 실제 다운로드.
- ChatGPT·Claude·Gemini 앱에서 각각 연결 승인과 실제 대화 중 파일 받기.
- 한컴 한글에서 최종 조판·인쇄·1쪽 여부. 외부 렌더러는 한컴 엔진과 동일하지 않습니다.
- 최대 길이·다양한 실제 업무 내용의 레이아웃 검증.
- 조직용 SSO/직원별 권한, 다중 인스턴스, 장기 부하 시험은 현재 범위에 포함되지 않습니다.
