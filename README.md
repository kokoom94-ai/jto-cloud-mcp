# JTO Cloud MCP

제공받은 제주관광공사 **사업계획·결과보고·1PAGE** 양식을 포함한 온라인 문서 생성 서버입니다. 직원 PC에 설치하지 않습니다. AI가 내용을 작성하고 이 서버가 원본 양식에 넣어 파일을 만든 뒤, 대화에 표시할 HTTPS 다운로드 링크를 돌려줍니다.

> 공개 MCP 연결 주소: https://jto-cloud-mcp.onrender.com/mcp — 인증 없음(No authentication). 직원 로그인·연결 암호 없이 사용합니다. 각 AI 대화창 시험과 서버 시험은 별도이며 이 저장소는 제주관광공사의 공식 인증 서비스를 뜻하지 않습니다.

| 요청 예시 | 선택되는 원본 양식 | 전달 파일 |
|---|---|---|
| 2027 중화권 마케팅 사업계획을 작성해줘 | 사업계획(안) | `report.hwpx` |
| 이 실적 자료로 결과보고서를 만들어줘 | 결과보고 | `report.hwpx` |
| 이 내용을 1PAGE 보고 자료로 만들어줘 | 1P 보고서 | `report.hwp` |

모든 결과에 `bundle.zip`, 검토용 Markdown/HTML, 출처, 미입력 목록, 검증 결과를 함께 제공합니다. 1PAGE는 원본 HWP 형식을 유지합니다. HWP를 HWPX로 이름만 바꾸지 않습니다.

## 온라인으로 배포하기

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/kokoom94-ai/jto-cloud-mcp)

Netlify를 사용하지 않습니다. 위 버튼은 Render 계정과 GitHub 접근 승인을 거쳐 서버를 배포합니다. 자동 결제·유료 업그레이드는 하지 않습니다.

1. Render에 로그인하고 배포 버튼을 누릅니다.
2. 공개 저장소 `kokoom94-ai/jto-cloud-mcp`를 선택해 Blueprint를 배포합니다.
3. 상태가 Live가 되면 Render의 서비스 주소를 확인합니다. 서버는 `RENDER_EXTERNAL_URL`을 자동 인식합니다.
4. 환경설정에서 자동 생성된 `JTO_ACCESS_PASSWORD`를 확인합니다. 이 값은 AI 연결 승인 화면에만 입력하며 대화창·GitHub에는 올리지 않습니다.
5. 각 AI 앱의 맞춤 커넥터에 **서비스 주소 + `/mcp`**를 등록하고 연결을 승인합니다.

**무료 설정은 체험용입니다.** Render 무료 서비스는 유휴 시 정지될 수 있고, 재시작/재배포하면 임시 파일과 로그인 토큰이 사라집니다. 그 경우 기존 다운로드 링크는 무효가 되고 AI 연결을 다시 승인해야 할 수 있습니다. 업무용으로 운영하려면 별도 비용을 확인한 뒤 지속 디스크를 사용하는 유료 인스턴스를 선택하세요. [배포 상세](docs/DEPLOY.md)

## GitHub 주소와 MCP 주소

- GitHub 주소: 소스와 양식·배포 안내를 공유하는 주소
- MCP 주소: 실행 중인 서버의 `https://…/mcp` 주소

GitHub 주소를 AI에게 보여주는 것만으로 모든 AI 앱에 서버가 자동 설치·연결되지는 않습니다. 사용자 또는 관리자의 최초 연결 승인은 필요합니다. [앱별 연결 안내와 제한](docs/CONNECT.md)

## AI의 작성 흐름

1. `jto_start_document(request)`로 양식과 작성 스키마를 받습니다.
2. 연결한 AI가 조사·집필합니다. 원문 확인 없는 출처나 실적을 만들면 안 됩니다.
3. `jto_validate_document`로 내용 구조·예산 합계·출처 ID·1PAGE 분량을 검사합니다.
4. `jto_generate_document`로 실제 파일을 만들고 반환된 URL을 사용자에게 제공합니다.

이 서비스 자체에는 외부 AI API 키가 필요하지 않습니다. 집필·웹 조사는 연결된 AI 앱의 기능을 사용합니다. 출처와 사실의 정확성은 형식 검사로 보증하지 않습니다.

## 원본 보존과 검증 범위

- 세 원본을 패키지에 포함하고 SHA-256으로 변경 여부를 검사합니다.
- 사업계획·결과보고는 원본 HWPX의 스타일·이미지·표지·용지 설정을 보존합니다.
- 1PAGE는 원본 HWP의 스타일·제목 상자·연녹색 요약 상자를 보존하고 안내 문구를 내용으로 교체합니다.
- 예산 미확인과 실제 0원을 구분합니다. 결과보고에 추정 실적이나 추정 집행액을 채우지 않도록 작성 지침을 제공합니다.
- ZIP/XML/표 구조 또는 HWP OLE/레코드 왕복 검사를 수행합니다.
- **한컴 한글의 실제 조판은 서버에서 보증하지 않습니다.** 1PAGE는 입력량을 제한하고 예시는 별도 렌더러에서 1쪽을 확인했지만, 모든 입력의 1쪽을 확정 검증하는 기능은 아직 없습니다.
- 제공된 글꼴은 파일에 포함하지 않습니다. 최종 열람 환경의 글꼴 설치 상태에 따라 줄바꿈이 달라질 수 있습니다.

## 다운로드·접근 제어

기본 공개 모드에는 로그인·연결 암호가 없습니다. 만료되는 다운로드 서명과 문서별 재조회 키를 사용합니다. 다운로드 URL은 링크를 가진 사람이 파일을 받을 수 있는 방식이며 기본 유효기간은 24시간입니다. 공유 목적이 아닌 문서의 링크를 공개 게시하지 마세요.

공개 서비스는 URL을 아는 사람이 사용할 수 있으며 전체 서비스 생성 한도는 시간당 100건입니다. 생성 문서 목록은 공개하지 않으며, 문서별 재조회 키가 있어야 링크를 다시 받을 수 있습니다. 소스 공개와 생성 문서 공개는 별개입니다. 선택적으로 JTO_AUTH_MODE=oauth를 설정하면 기존 OAuth 모드를 사용할 수 있지만 직원 공유용 기본 설정은 public입니다.

## 개발·검증

Python 3.12 이상에서:

```sh
pip install -e '.[test]'
pytest -q
```

서버 실행에는 `JTO_PUBLIC_BASE_URL`, `JTO_ACCESS_PASSWORD`(16자 이상), `JTO_SIGNING_KEY`(32자 이상), `JTO_DATA_DIR`이 필요합니다. 로컬 개발 외에는 HTTPS 주소를 사용합니다. 서버는 단일 인스턴스·단일 프로세스 기준입니다.

```sh
jto-cloud-mcp
```
